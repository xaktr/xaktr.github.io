# Ankit Raj — Portfolio (aktr.me)

A minimal, editorial-style React portfolio built with Vite.

## Tech Stack
- React 18
- Vite
- Lucide React
- Vanilla CSS

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```

Deployed automatically to [aktr.me](https://aktr.me) via GitHub Actions.
